# Support

Need a paw? Here's where to go.

| You want to | Go to |
|---|---|
| Learn the basics | [docs/getting-started.md](docs/getting-started.md) and [docs/glossary.md](docs/glossary.md) |
| Read the full docs | [docs.dogesoft.io](https://docs.dogesoft.io) |
| Look something up on chain | [explorer.dogesoft.io](https://explorer.dogesoft.io) |
| Ask a question | Open a **Question** issue in this repo |
| Report a bug or a DIFF | Open a **Bug report** issue |
| Report a security problem | Follow [SECURITY.md](SECURITY.md), confidentially |
| Higher API limits or a partner key | DM [@dogesoftio](https://x.com/dogesoftio) on X, or use the [developer access request](https://docs.dogesoft.io/explorer/api) form |
| Say hi and follow along | [@dogesoftio](https://x.com/dogesoftio) on X |

Never share your seed phrase or private key with anyone, including people who say they're from Doge Soft.
