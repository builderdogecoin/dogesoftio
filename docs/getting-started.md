# Getting started

Welcome, Doge Kin. Whether you hold your first DOGE or you've been inscribing Doginals since day one, this page gets you moving in a few minutes.

## 1. What Doge Soft is

Doge Soft is the friendly layer for Dogecoin. One Orbit, every piece doing one job:

- **Wallet**: self-custody DOGE, Doginals and DRC-20 Coins. Your keys stay on your device. Browser extension, Android and Apple.
- **Explorer**: [explorer.dogesoft.io](https://explorer.dogesoft.io) shows transactions, inscriptions, balances and history, without the fog.
- **Names**: readable **.doge** names inscribed to your wallet. Pay once, no renewals.
- **Marketplace and Launch**: list, buy and launch Doginals collections.
- **Bridge**: move DRC-20 Coins between Dogecoin L1 and the Doge Soft L2.

All of it reads one index, and that index reads **Dogecoin Core**.

## 2. Look something up (no install)

Open [explorer.dogesoft.io](https://explorer.dogesoft.io) and paste a Dogecoin address, a transaction id, an inscription id or a name like `soft.doge`.

## 3. Ask the API (one terminal command)

```bash
curl https://explorer.dogesoft.io/api/health
```

You'll see the indexed block height and how far it is behind the chain tip (usually 0 or 1 block). Next stop: [API quickstart](api-quickstart.md).

## 4. Check us yourself

If you run Dogecoin Core, you don't have to take our word for anything. See [Verify with your own Core](verify-with-your-own-core.md).

## 5. Learn the words

The [glossary](glossary.md) covers everything in plain English. Remember: on Doge Soft they are **DRC-20 Coins**, not tokens.
